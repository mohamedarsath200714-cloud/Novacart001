About NovaCart

NovaCart is a modern e-commerce product catalog created using responsive web technologies.

The application demonstrates client-side navigation, dynamic product rendering, search, category filtering and shopping cart management.

Cart information is stored locally in the browser so users can continue their shopping experience without losing their selected products.

The architecture can be extended with Node.js, Express and MongoDB for a complete full-stack production application.
